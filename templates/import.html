🔗 LinkedIn Scraper

Run the Playwright scraper script once to pull your connections and recent message history directly from your LinkedIn account.

# 1. Install dependencies
pip install -r requirements.txt
playwright install chromium

# 2. Run the scraper (opens a real browser window)
python linkedin_scraper.py

# Enter your LinkedIn credentials when prompted.
# The script will load your connections + messages
# and import them directly into the database.

Your credentials are never stored — they're only used in the browser session.
